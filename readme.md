# MondrianPartB

Nesta segunda parte, parti do código desenvolvido anteriormente e introduzi um elemento generativo através da função random(), aplicado aos três blocos de cor: vermelho, azul e amarelo. Através da variação aleatória dos valores de cor, procurei criar uma sensação de brilho digital, conferindo aos blocos uma aparência ligeiramente instável e dinâmica. A intenção foi introduzir um elemento de imprevisibilidade na composição original, mantendo a sua estrutura geométrica e o equilíbrio visual, mas aproximando-a de uma estética digital.
